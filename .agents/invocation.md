# Invocation axis

Every promoted skill is either:

| Axis | Meaning | Examples |
|------|---------|----------|
| **user-invoked** | User names the skill or slash command | `impact`, `sdlc`, `update-models`, `shakedown`, `ask-fde` |
| **model-invoked** | Orchestrator or pipeline calls via Skill tool | `recon`, `slice`, `raise`, `conduct`, `model-routing` |

Never mix both in one `SKILL.md`. Split skills instead.
