The repository gains a trace spine and a contract harness, and sixteen capabilities ported from the reference set arrive as drafts bound to both.

`skills/core/TRACE.md` defines the run trace: the record a skill writes while it works, holding what it was given, what it decided, what evidence it saw, and what it left open. A trace lives beside the gate ledger it accompanies, at `.grit/<scope>/TRACE.md`, rather than in a second state directory, because a repository carrying two partial records of the same run has gained disagreement rather than an audit trail. The document also defines the four-key contract block every new skill carries — its invocation axis, the limb of the repository's promotion test it satisfies, the tool verbs it may use, and the kind of entry it appends — and the replay protocol a later session follows to resume work it did not start.

Two harness files enforce that contract. `test/structure/frontier-contracts.test.mjs` checks that every draft declares a thesis limb from a closed set, draws its verbs from a closed set and names a human approval step whenever it declares the outward-facing `publish` verb, agrees with its own title on the invocation axis, holds a basename unique against every promoted skill, respects group independence, points at every doctrine sibling it ships, and stays out of the README and the plugin manifest until it is promoted. `test/structure/house-voice.test.mjs` enforces the rule `.agents/writing-docs.md` states — no marketing vocabulary, no first-person cheerleading, no exclamation points or decorative emoji, American spelling, and a description substantial enough for a model to route on. Words with a legitimate technical sense here stay off the banned list, because a check that forces correct prose to be mangled teaches authors to work around the harness rather than to write well.

All sixteen ported capabilities ship promoted, and `drafts/` is empty again.

The developer group takes seven. `tdd` drives one vertical slice from a failing test to passing code. `debug` runs a gated diagnosis loop that reproduces before it theorizes and tests one falsifiable hypothesis at a time. `prototype` answers a single design question with code it then deletes or deliberately graduates. `refactor` surveys a codebase for deepening opportunities and stops for a person to choose. `glossary` builds the project's shared language, each term carrying an explicit list of the near-synonyms it replaces. `triage` moves an incoming report through one role at a time using the repository's own label vocabulary rather than an invented one. `wizard` generates a resumable script for the steps only a human can perform, and refuses to generate one where the agent could do the work itself.

The core group takes two. `research` investigates against primary sources and writes cited findings into the repository, labeling a claim it could not source rather than asserting it quietly. `retro` closes the harness loop the trace spine opened: it reads accumulated traces, treats a single failure as an anecdote and a pattern across three or more runs as a finding, separates a defect in the instructions from a defect in following them, and proposes changes as a pull request a person approves. It never merges its own work, because a system that both writes and accepts its own rules has no gate left.

Productivity grows to five with `handoff`, which projects a run's trace into a document the next session picks up cold and carries what was tried and abandoned, the part a summary drops and the next session would otherwise retry; `questionnaire`, which turns a decision you cannot answer alone into questions for the person who can, interrogating the send rather than the subject; `wait-what`, which diagnoses why an explanation failed before rewriting a word of it; and `teach`, which carries a concept across sessions and checks understanding by application rather than recall.

The writing group opens with three, converting a charter into a practice. `freewrite` holds generation apart from judgment and keeps contradictions rather than resolving them. `outline` orders fragments into beats and grounds every term before a beat leans on it. `draft` renders prose one beat at a time against a coverage map, so which beats have paragraphs is auditable rather than felt.

Each promoted skill carries a documentation page, a wiki stub, an llms.txt entry, an `ask-fde` routing line, and a case in the selection eval. The routing table now holds 51 cases against a catalog of 50 skills, re-measured rather than edited, because a scorecard is a record of a run.
