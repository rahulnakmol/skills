Add an Amp adapter. Amp becomes the sixth tool the catalog runs in. `scripts/install-amp.sh` turns a selection of one skill, one group, or everything into the `amp skill add` calls Amp needs, adding `core` to a group, the required skill to a theme skill, a doctrine wrapper per group, and the `tqn` router; it installs into the current project or, with `--global`, for one person on one machine, and it exits non-zero when Amp reports a failure. `scripts/publish-amp-skills.sh` stages the same selection into an Amp-hosted Personal Skills or Workspace Skills repository, which syncs to every orb the owner or the workspace opens; it commits and stops before the push.

Two Amp-only skills live under `adapters/amp/skills/`. `core-doctrine`, `developer-doctrine`, and `pm-doctrine` are generated by `scripts/gen-amp-doctrine.mjs` from each group's root documents, because Amp installs only directories that hold a `SKILL.md`; the copies are byte-identical and `--check` runs in CI. `tqn` maps the catalog onto Amp: where a doctrine citation resolves, which Amp capability to prefer where one overlaps a catalog skill, how `agent` and `human` nodes run as Task subagents, orb threads, and schedules, and how `model-routing` tiers bind to Amp modes. No skill under `skills/` is copied or changed to name a tool.

`adapters/amp/plugin/tqn-grit.js` is an opt-in Amp plugin that enforces the `grit` ledger at turn end. It runs the vendored `stop-hook.mjs` on Amp's `agent.end` event and continues the turn with the unmet list while gates remain, rejects tool edits to the approval store and the hook state, and adds two command-palette entries for gate status and check approval. `scripts/install-adapters.sh --tool amp-plugin` installs it for one machine; `skills/core/grit/HOOKS.md` gains an Amp section; `test/scripts/grit-amp-plugin.test.mjs` covers it with a stand-in `PluginAPI`.

`.agents/setup` and `.agents/resume` link every skill into `.agents/skills/` for an orb opened on this repository and turn off Amp's commit trailers there. ADR 0010 records the decisions. `wiki/Tool-Guidance.md`, `wiki/Installation.md`, `.agents/install-block.md`, `README.md`, and `AGENTS.md` describe the new tool.
