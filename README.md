# rahulnakmol/skills

Multi-tool AI skills monorepo: SDLC orchestration, impact pipeline, model registry, and adapters for OpenCode, Claude, Codex, Cursor, and Copilot.

## Install

```bash
npx skills@latest add rahulnakmol/skills
./scripts/install-adapters.sh
```

See [wiki/Home.md](wiki/Home.md) and [wiki/Installation.md](wiki/Installation.md).
