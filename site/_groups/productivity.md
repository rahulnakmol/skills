Productivity skills automate the personal and team workflows that do not belong to software delivery or product management specifically, but that cost real time when done by hand on every repeat. The group grows one skill at a time, each one earning its place by addressing a problem a team actually runs into, rather than by filling out a category in advance.

The group depends on no other group and installs on its own, for a team or an individual who wants what it offers without adopting the developer or pm pipeline alongside it.

Its one shipped skill, `brief`, addresses a problem every team adopting agents meets early: a rule only exists where a tool actually loads it. Claude Code reads `CLAUDE.md`; OpenCode and Codex read `AGENTS.md`; Cursor and GitHub Copilot read their own scoped instruction files; Claude Desktop and Cowork read no repository file at all. The same paragraph placed in the right file changes an agent's behavior, and placed in the wrong one changes nothing. `brief` splits a team's working agreement into definitions, rules, and references, writes each rule with a trigger and an observable result, and places each layer in the file the tool in question actually reads — one canonical copy, with every other surface pointing at it.

```bash
npx skills@latest add tqnonline/skills
./scripts/install-adapters.sh
```
