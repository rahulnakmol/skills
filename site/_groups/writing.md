You read every page on this site expecting one voice: plain sentences, no marketing language, facts before opinion. Writing is the group that would turn that expectation into a checkable skill, instead of a habit every author has to remember on their own. It has not shipped one yet.

`skills/writing/README.md` states the charter in one sentence: skills that make writing better, for people and agents alike. Three areas are named as planned work: editorial review of architecture decision records and technical documents, documentation-quality linting, and enforcement of the explainer voice this repository already holds itself to. None carries a committed date.

This repository's own rule is that promoted work lives under `skills/`, and everything else lives in `drafts/`. As of this writing, no `drafts/` directory exists either, so writing has a stated direction and no skill in progress toward it that this page can point to.

Because the group has no skill yet, installing the full pack or naming writing specifically adds nothing beyond this charter. The install command below is the one every group in this catalog uses, and it will begin carrying writing's own skills once the group has one to ship.

```bash
npx skills@latest add tqnonline/skills
./scripts/install-adapters.sh
```

A charter with no skill behind it is a promise, not a practice; this page states that plainly instead of presenting an empty group as a finished one.
