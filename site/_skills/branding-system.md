## What it does

Branding System is the model-invoked engine behind six user-invoked themes. It defines one independent verbal identity, surface rules, an A+ internal accessibility bar, provenance boundaries, environmental sampling, generated-video prompts, motion, color grading, and an output receipt. A deterministic builder creates CSS and JSON tokens, a press palette, an HTML specimen, and a checksummed manifest.

<ul class="benefits">
<li>All themes use the same semantic role schema and delivery status words.</li>
<li>Verbal identity remains independent from every source palette and provider.</li>
<li>Physical colors require measured samples, while video requires tagged color pipelines and encoded-file checks.</li>
<li>The validator checks inputs it can prove and refuses to turn them into a whole-artifact certification.</li>
</ul>

## A working example

QuenServe E1 has already selected Nord dark for product UI and video graphics, with Nord light for its release PDF and wall sampling brief. The engine validates the profile, generates the two starter kits, and applies one direct, audience-centered, grounded, and constructive verbal identity to all four artifacts.

The UI review covers interaction states, keyboard use, semantics, reflow, forced colors, and reduced motion. The PDF review covers source comparison, reading order, tags, links, and embedded fonts. The wall remains a measured sampling brief. The video review covers captions, transcript, audio description, flash, loudness, Rec.709 and P3 transforms, and a full encoded-file watch.

## Common questions

<details class="qa"><summary>Is A+ an accessibility certification?</summary><div class="qa-body"><p>No. It is an internal quality bar over a WCAG 2.2 AA baseline. The system reports exact checks and never treats a palette as whole-artifact certification.</p></div></details>

<details class="qa"><summary>Does the starter kit finish the design?</summary><div class="qa-body"><p>No. It provides deterministic tokens, a specimen, a press mapping, and checksums. Native layout, production, accessibility, and rendered review still remain.</p></div></details>

<details class="qa"><summary>Can it generate one lookup table for a theme?</summary><div class="qa-body"><p>No. A reusable three-dimensional lookup table follows an approved grade for named input, working, and output spaces. It is never derived directly from palette hex values.</p></div></details>

## It's working if

- All six themes pass one schema and one deterministic validation command.
- Every artifact receipt distinguishes automated checks, rendered checks, physical proof, rights, and limitations.
- Provider or palette sources never receive credit for local doctrine they did not publish.
- No artifact advances to production until a named owner approves the exact files and specification.

## Where it fits

Branding System is a model-invoked dependency, not a seventh public aesthetic. Each theme declares the dependency so a single-theme link remains usable. Press stays independent and consumes the generated palette only when an approved markdown document needs rendering.
