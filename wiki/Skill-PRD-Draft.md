# PRD Draft

User-invoked PRD drafting and structural validation from an approved epic manifest. Use to generate one PRD per epic with INVEST-compliant user stories, Given-When-Then acceptance criteria, success metrics, and a grill pass, then to run the nine-check structural validation that ends in a PASS, PASS WITH WARNINGS, or FAIL verdict before the Quality gate. Also use to check, validate, or confirm the completeness of a PRD that already exists.

Full documentation: https://tqnonline.github.io/skills/prd-draft/
