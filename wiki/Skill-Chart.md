# Chart

User-invoked charting of work too large for one agent session. Turns an initiative into a chart of decision tickets on the tracker, each sized to one session, resolved one decision at a time by a PM and an agent team. Use when an initiative is too big, too uncertain, or too cross-cutting to run the pm pipeline in a single pass, and to read status off the chart instead of asking people for updates.

Full documentation: https://tqnonline.github.io/skills/chart/
