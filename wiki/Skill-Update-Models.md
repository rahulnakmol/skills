# Update Models

User-invoked model registry curation. Research provider catalogs, propose updates to models.md and adapters, open a reviewable PR. Serves every group in this repository, developer and pm alike — the registry it curates is not developer-only. Use on schedule or when models deprecate. Where a tool chooses the model behind an effort mode itself, the registry maps tiers to modes there and needs no identifier update for it.

Full documentation: https://tqnonline.github.io/skills/update-models/
