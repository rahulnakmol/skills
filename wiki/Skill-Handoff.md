# Handoff

User-invoked compaction of an in-flight run into a handoff document a cold reader can pick up. Use when a session ends with work unfinished, when the context window is nearly full, or when work passes to another agent or person who was not present for it. Where the tool keeps session history across threads, record the thread link in the document; the document still stands alone for a cold reader.

Full documentation: https://tqnonline.github.io/skills/handoff/
