# Brief

User-invoked authoring of the rules, definitions, and boundaries a team's AI agents read. Breaks a working agreement into always-loaded rules, a shared glossary, and on-demand references, then places each part in the file the tool actually loads — Claude Code, Claude Desktop, Cowork, OpenCode, Codex, Cursor, Copilot, and Amp. Use to write or revise CLAUDE.md or AGENTS.md, to set team-wide agent rules, or when agents keep ignoring an instruction the team believes it has already given.
