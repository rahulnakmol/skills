# Group: Productivity

Productivity skills are delightful automations: the personal and team workflows worth never doing by hand again. The group grows the way the others have — one skill at a time, each earning its place by being used, with the repetitive middle automated and the judgment calls left where they belong, with a person.

One skill has shipped.

| Skill | Invocation | Purpose |
|-------|------------|---------|
| [Brief](Skill-Brief) | user | Writes the rules, definitions, and boundaries a team's agents read, placed per tool surface |

`brief` addresses a problem every team adopting agents meets early: a rule only exists where a tool actually loads it. Claude Code reads `CLAUDE.md`, OpenCode and Codex read `AGENTS.md`, Cursor and Copilot read their own scoped instruction files, and Claude Desktop and Cowork read no repository file at all — so the same paragraph changes behavior in one place and nothing in another. The skill separates a team's working agreement into definitions, rules, and references, writes each rule with a trigger and an observable result, places the layers per surface with one canonical file and pointers elsewhere, and verifies by running real work rather than by rereading the file. See [Skill-Brief](Skill-Brief) and the [Tool guidance](Tool-Guidance) page for how a capability degrades when a tool cannot run it.
