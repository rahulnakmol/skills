# Tdd

Model-invoked test-first discipline. Use to build a feature or fix a bug one vertical slice at a time, writing a failing test that fails for the right reason before the implementation exists, and refactoring only under green.

Full documentation: https://tqnonline.github.io/skills/tdd/

Source: [SKILL.md](https://github.com/tqnonline/skills/blob/main/skills/developer/tdd/SKILL.md)
