# Writing group

Skills that make writing better, for people and agents alike.

The group ships one sequence, in three stages, because the failure it addresses is a process failure rather than a style failure. Most writing goes wrong before a sentence is judged: material is edited while it is still being gathered, structure is inferred from the order the material happened to arrive, and prose is written in a single pass that leaves every paragraph the same weight. Each stage here isolates one of those, and each is invoked on its own.

- `freewrite` — explore. Mine raw fragments with generation held apart from judgment, keeping contradictions rather than resolving them, because a contradiction is usually where the real idea is hiding.
- `outline` — structure. Order the fragments into beats, where a beat is one move the reader makes, and ground every term before a beat leans on it.
- `draft` — render. Write prose one beat at a time against a coverage map, so which beats have paragraphs and which do not is auditable rather than felt.

The stages run in order for a new piece, and independently for repair: an article that reads as a list of true statements needs `outline`, not more drafting.
