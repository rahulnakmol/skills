# PM group — the AI-native transformation practice

Seventeen promoted skills: the business side of the same AI-native transformation coin as the developer group. The goal, stated and tested: the PM becomes a UX-driven, outcome-driven, efficient agentic owner of problem-solving — reasoning through problems with an agent fleet whose blind spots the PM assesses, and whose coverage closes the PM's own blind spot in return. PMs work one hat at a time, product or transformation, never both — the keepers of the transformation, with visibility into the delivery teams they steer toward a north star of efficiency and productivity as transformation value, every initiative grounded in cost including the agent fleet's own.

Work too large for one agent session is charted before it is run: `chart` turns an initiative into decision tickets on the tracker, each sized to one session, so a PM steering an agent team always knows which decisions can be taken today and a sponsor can read status without asking for it. Four human gates — Framing, Investment, Quality, Commitment — mirror the developer group's four; approval stays human at every one. See the root README and wiki/Group-PM.md.
