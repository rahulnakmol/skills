# Impact (user-invoked)

Turn ideas into an approved PRD and pipeline handoff.

## When to invoke

- New initiative, major feature, or brownfield change needing alignment
- User provides notes, transcripts, or vague intent

## Procedure

1. **Intake** — fast-cut PRD (`PRD-TEMPLATE.md`)
2. Brownfield? → `Call the Skill tool with "recon"` first; attach brief
3. **Grill** — `GRILL.md` + `VALUE.md` until stop or approval (`GATES.md`)
4. Optional branded PDF → `Call the Skill tool with "press"`
5. Hand off to `slice` only after G2 sign-off

## Stop conditions

- No business value section → cannot advance to `slice`
- User has not signed PRD → stop at G2

## Output contract

PRD markdown ≤10 pages + `.impact.json` project metadata update.

## Sibling skills

- `recon`, `slice`, `raise`, `press`
