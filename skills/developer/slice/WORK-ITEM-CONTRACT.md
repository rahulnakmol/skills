# Work item contract

Every issue from `raise` must include:

1. **Goal** — measurable outcome
2. **SPEC-TS snapshot** — from PRD
3. **Pod charter** — roles and adapters
4. **Delivery flow** — gates and verifiers
5. **Execution manifest** — headless block
6. **Pickup protocol** — labels: `raised → critiqued → clarified → ready → in-progress → done`

Agents **critique first**; implement only at `ready`.
