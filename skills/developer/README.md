# Developer group — the AI-native SDLC

Fifteen promoted skills: the software delivery lifecycle rebuilt for humans working with trusted agents — inception through maintenance, four human gates, and verified agent work between them. The acceptance-gate ledger that makes "done" a measured claim rather than a reported one is `grit`, which lives in the `core` group because the pm group calls it too; this group references it, and references no other group. Directory rename to `ai-native-sdlc` is planned and tracked as its own change. See the root README and wiki/Group-Developer.md.
