# Loop vs graph vs hybrid rubric

| Question | If yes → |
|----------|----------|
| Is done machine-checkable with one verifier? | **Loop** |
| Single bounded context? | **Loop** |
| Multiple independent workstreams? | **Graph** |
| Mixed human gates + parallel lanes? | **Hybrid** |

See `LOOP.md` and `GRAPH.md` for harness mapping.
