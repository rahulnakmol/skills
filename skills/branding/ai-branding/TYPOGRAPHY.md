# AI branding typography

The provider variants keep separate pairings. Anthropic uses Poppins for display and Lora for body text, matching the open-source type references in its published skill. JetBrains Mono carries code and production data.

The OpenAI option does not use OpenAI Sans because that font is not distributed as an open-source family. Manrope supplies the geometric display role, Source Serif 4 supplies editorial reading, and JetBrains Mono remains the technical face. These are local substitutes, not official OpenAI typography.

## Pairing rules

- Use Poppins or Manrope for headings, navigation, short labels, and large numerals.
- Use Lora or Source Serif 4 for paragraphs, narrative captions, reports, and spoken-script documents.
- Use JetBrains Mono for code, identifiers, measurements, and provenance records.
- Keep body lines near 45 to 75 characters and line height from 1.5 to 1.7.
- Use the display face sparingly in all capitals. Use sentence case by default.
- Never mix the Anthropic and OpenAI pairings in one identity.

## Language support

Use a Noto Sans family for the display role and a Noto Serif family for reading when the target script needs them. Test real translated copy for shaping, punctuation, numerals, line breaks, and expansion. Package each used font file with its OFL-1.1 license.
