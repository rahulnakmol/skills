# AI branding sources

Sources were checked on September 4, 2026. Recheck current brand terms before production because company guidance can change without this repository changing.

## Provider references

- [Anthropic skills: brand guidelines](https://github.com/anthropics/skills/tree/main/skills/brand-guidelines), Apache-2.0 for the repository code. The published skill provides a limited palette, Poppins, Lora, and artifact post-processing guidance. It does not make this skill's interface, dark mode, accessibility, physical, video, personality, product, pricing, or legal guidance official.
- [OpenAI brand guidelines](https://openai.com/brand/), current provider terms apply. OpenAI Sans is not an open-source font, so this skill does not distribute or specify it.

Code licenses do not grant trademark rights. Provider names, logos, product icons, slogans, trade dress, and endorsement language require separate review under current terms.

## Open-source fonts

- [Poppins](https://github.com/google/fonts/tree/main/ofl/poppins), [Lora](https://github.com/google/fonts/tree/main/ofl/lora), [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope), [Source Serif 4](https://github.com/google/fonts/tree/main/ofl/sourceserif4), and [JetBrains Mono](https://github.com/google/fonts/tree/main/ofl/jetbrainsmono): SIL Open Font License 1.1
- [Noto fonts](https://github.com/notofonts), SIL Open Font License 1.1 for script-specific fallbacks; verify the license in each selected family

Package exact license files with distributed fonts. The local teal, status colors, semantic mapping, substitute fonts, surface rules, and motion rules belong to this skill system rather than either provider.
