# Catppuccin typography

Syne provides wide, geometric display forms for campaign lines, feature headings, and large numerals. Its personality is strongest at display size. Keep it away from dense controls, captions, and long paragraphs.

Nunito Sans carries body copy and interface text with round forms that support the palette without imitating it. JetBrains Mono distinguishes code, data labels, measurements, and production annotations.

## Pairing rules

- Use Syne at 30 pixels or larger. Keep headings short enough that its width does not force awkward wrapping.
- Use Nunito Sans for paragraphs, navigation, controls, tables, captions, and subtitles.
- Keep body lines near 45 to 75 characters and line height from 1.45 to 1.65.
- Use pastel color for selective emphasis. Build most hierarchy with type size, weight, space, and alignment.
- Use sentence case for headings and controls. Use tabular numbers for data.

## Language support

The primary families do not cover every writing system. Use a Noto Sans family made for the target script while preserving display, body, and mono roles. Test real translation for shaping, punctuation, line breaks, expansion, and weight. Package each font file with its OFL-1.1 license.
