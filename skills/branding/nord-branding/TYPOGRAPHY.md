# Nord typography

Space Grotesk provides geometric headings with enough irregularity to avoid a generic corporate tone. Source Sans 3 carries interfaces, reports, captions, and long reading. JetBrains Mono carries code, labels, measurements, and provenance.

## Pairing rules

- Use Space Grotesk for headings, navigation, large numerals, and short labels.
- Use Source Sans 3 for paragraphs, controls, tables, captions, subtitles, and wayfinding copy.
- Use JetBrains Mono for code and compact metadata. Do not use it for long explanations.
- Keep body lines near 45 to 75 characters and line height from 1.45 to 1.65.
- Build hierarchy with space, scale, weight, and alignment before adding another blue.
- Use sentence case and tabular numerals where data alignment matters.

## Language support

Use a Noto Sans family built for the target script when the primary families lack coverage. Preserve the display, body, and mono roles, then test real translation for shaping, punctuation, numerals, expansion, and line breaks. Package each used font with its OFL-1.1 license.
