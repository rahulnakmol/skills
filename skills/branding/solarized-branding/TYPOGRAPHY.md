# Solarized typography

IBM Plex Serif gives headings and long-form openings an editorial voice. IBM Plex Sans carries interfaces, body text, captions, and wayfinding. IBM Plex Mono carries code, data, measurements, and production notes. The shared family structure keeps changes of role clear without making the pairing feel assembled from unrelated parts.

## Pairing rules

- Use IBM Plex Serif for display headings, pull quotes, and long-form section openings.
- Use IBM Plex Sans for paragraphs, controls, tables, captions, subtitles, and environmental copy.
- Use IBM Plex Mono for code, identifiers, measurements, and compact metadata.
- Keep body lines near 45 to 75 characters and line height from 1.45 to 1.65.
- Use size, weight, and space before adding another palette accent.
- Use sentence case. Use tabular numbers where values align in columns.

## Language support

Use the matching Noto Serif or Noto Sans family for the target script when the Plex family lacks coverage. Preserve role and hierarchy, test real translated copy, and allow expansion rather than shrinking the text. Package each used font with its OFL-1.1 license.
