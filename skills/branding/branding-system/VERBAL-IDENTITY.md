# Shared verbal identity

This doctrine is written for this skill system. It does not reproduce another organization's voice, slogans, manifesto, vocabulary swaps, or business-unit language.

## The voice

The common voice has four traits.

1. **Direct.** Name the point early. Use active voice and concrete verbs.
2. **Audience-centered.** Start with the reader's situation, decision, or task. Do not start with the organization speaking.
3. **Grounded.** Support a claim with an observed fact, a number, a source, or a clearly labeled judgment.
4. **Constructive.** Show what can happen next without hype, false certainty, or forced cheerfulness.

The themes change visual tone, not truthfulness or meaning. A dark mode does not become ominous. A pastel profile does not become casual. A company-inspired profile does not borrow that company's voice.

## Message architecture

Use the smallest set of these beats that carries the message:

1. **Situation:** what changed or what the audience is trying to do.
2. **Consequence:** why it matters to this audience now.
3. **Response:** the action, offer, or decision in plain terms.
4. **Evidence:** the fact that supports the response and its limits.
5. **Next step:** one clear action, owner, or deadline.

Lead with the consequence in alerts and operational messages. Lead with the audience goal in guidance. Lead with the finding in reports. Long-form narratives may establish the situation first, but they should not delay the point for effect.

## Sentence and word choices

- Prefer short sentences with one idea.
- Use familiar words before specialist terms. Define a necessary technical term on first use.
- Use contractions only when the channel already uses conversational language.
- Write headings as information, not decoration. A heading should let a scanning reader predict the section.
- Use specific quantities and dates when they are known. State uncertainty when they are not.
- Use inclusive examples. Do not infer gender, ability, culture, role, or technical confidence from a name or audience segment.
- Write alt text for purpose and information. Do not repeat nearby captions.

## Channel modulation

| Channel | Keep | Adjust |
|---|---|---|
| Product and service UI | Direct, grounded | Shorten to the decision and recovery path |
| Email | Audience-centered | Put the request and deadline near the start |
| Social | Constructive | Use one claim and one supporting fact; do not compress away context |
| Report or document | Grounded | Add method, sources, limits, and decision record |
| Presentation | Direct | Put one argument on each slide and move detail to notes |
| Environmental copy | Direct | Shorten for distance, movement, and the available reading time |
| Video and audio | Audience-centered | Write for speech, captions, transcripts, and audio description together |

## Review questions

- Can the intended reader state the point after one pass?
- Does every important claim show its evidence or its uncertainty?
- Is the next action clear without relying on color, placement, or prior context?
- Does translated copy have room to expand without truncation or a smaller type size?
- Does the message respect the audience's time and agency?
