# Gruvbox typography

Bricolage Grotesque gives large headings an uneven but controlled industrial character. Newsreader brings contrast and long-form pacing to paragraphs, reports, and scripts. IBM Plex Mono carries interfaces, code, tables, measurements, and production notes.

## Pairing rules

- Use Bricolage Grotesque for large headings, campaign lines, labels, and section numerals. Limit unusual widths or alternates to display text.
- Use Newsreader for long paragraphs, pull quotes, and editorial captions.
- Use IBM Plex Mono for short interface labels when a technical tone is useful, but keep paragraphs in Newsreader.
- Keep body lines near 45 to 75 characters and line height from 1.5 to 1.7.
- Use one strong accent per composition. Let type weight, rules, and blocks carry the rest of the hierarchy.
- Use tabular numerals in dashboards and production records.

## Language support

Use Noto Sans for display and a Noto Serif family for long reading when the target script needs them. Match role, weight, and approximate width rather than forcing unsupported glyphs from the Latin pairing. Test real translated copy and package each used font with its OFL-1.1 license.
